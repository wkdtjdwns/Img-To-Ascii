# 4. 제작 동기 및 목적

1. **아스키 아트를 구경하다가 뭔가를 만들어보고 싶다고 생각함.**
2. **그래서 친구에게 그릴만한 주제가 없을까 하고 물어봤는 데 비트맵 이미지를 아스키 아트로 바꾸는 프로그램이라도 만들었냐고 물어봐서 어? 하고 만들게 됨.**

<br>

# 5. 구현 알고리즘

1. **다중 경로를 통한 이미지 데이터 로드 및 최적화**
2. **백그라운드 비동기를 활용한 이미지 처리 파이프라인**
3. **픽셀-문자 치환 알고리즘 및 멀티 포맷 가공**
4. **상태 머신 기반의 UI 흐름 제어 및 출력**

<br>

# 6. 구현 기능

- **하이브리드 이미지 입력 인터페이스**
- **실시간 메타데이터 파싱 및 정보 표출**
- **커스텀 해상도 및 폰트 유연성**
- **다중 스타일 문자셋 매핑**
- **멀티 포맷 저장 및 내보내기**
